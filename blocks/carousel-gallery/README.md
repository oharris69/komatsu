# carousel-gallery

Custom **carousel** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Videos: YouTube slides (poster + play button, click plays the nocookie embed in place), title and description below | `videos` |

## Universal Editor fields

N/A (Document Authoring project)

## Content model

- image + caption per slide
- videos option: one row per slide: poster picture | YouTube link (https://www.youtube.com/watch?v=<id>), optional <strong> title paragraph and description paragraph(s)
